# Сторонние компоненты

Код MLVH распространяется по MIT (см. `LICENSE`). Ниже — зависимости и их
лицензии, а также ограничения, о которых стоит знать при форке.

## Основные зависимости

| Компонент | Лицензия | Использование |
|---|---|---|
| PySide6 (Qt for Python) | LGPL-3.0 | интерфейс |
| edge-tts | LGPL-3.0 | движок озвучки Edge |
| pygame-ce | LGPL-2.1+ | воспроизведение звука |
| openai | Apache-2.0 | клиент DeepSeek API |
| python-dotenv | BSD-3-Clause | чтение `.env` |
| chatterbox-tts | MIT | локальный движок (опционально) |
| silero (пакет) | MIT | локальный движок (опционально) |
| torch, torchaudio | BSD-3-Clause | рантайм локальных моделей |
| transformers | Apache-2.0 | зависимости Chatterbox |
| onnxruntime | MIT | водяной знак perth |
| librosa | ISC | аудио в Chatterbox |
| numpy | BSD-3-Clause | вычисления |

Полные тексты лицензий — в пакетах внутри `.venv` (`*.dist-info/LICENSE`).

## Ограничения, которые важно учитывать

### Веса Silero — CC BY-NC 4.0

Пакет `silero` распространяется по MIT, но **веса модели `v5_ru.pt`
лицензированы CC BY-NC 4.0** — некоммерческое использование. То есть:

- код MLVH можно брать в коммерческий продукт (MIT это разрешает);
- но использовать вместе с движком Silero в коммерческом продукте — нельзя.

Файл модели скачивается отдельно и в репозиторий не входит.

### Edge TTS — неофициальный канал Microsoft

Библиотека `edge-tts` (LGPL-3.0) обращается к сервису Edge Read Aloud. Это
не публичный API Microsoft: условия использования сервиса могут меняться,
доступ — блокироваться. Замена — локальные движки (Silero, Chatterbox).

### LGPL и сборка в один файл

PySide6 и pygame-ce распространяются по LGPL. При запуске из Python всё
в порядке: библиотеки лежат отдельными файлами, и пользователь может их
заменить. Если собирать `.exe` через PyInstaller, нужно сохранить возможность
подмены Qt/pygame (не сливать их в один бинарник или приложить объектные файлы).

### Chatterbox и водяной знак

Модель Chatterbox (MIT) встраивает в аудио невоспринимаемый водяной знак
PerTh. В MLVH он отключён для потоковых кусков (`chatterbox_watermark: false`),
потому что файлы сразу удаляются. Если сохраняете аудио в файл — включите
метку обратно.

### Голоса для клонирования

Chatterbox клонирует тембр по образцу. Используйте только те записи, на
которые у вас есть права: чужой голос — это персональные данные.

### Google Chrome — проприетарный, не поставляется

MLVH не включает Chrome, не скачивает его и не требует для обычной работы.
Если Chrome установлен, он может запускаться в headless-режиме, чтобы
отрисовать страницу с JavaScript: одноразовый профиль в `%TEMP%`, логины и
история пользователя не используются. Условия использования Chrome — лицензия
Google. Без Chrome поиск и обычные страницы работают, JS-страницы остаются
пустыми.

### Новые пакеты для интернета и MCP не нужны

Поиск, загрузка и разбор HTML сделаны на стандартной библиотеке Python
(`urllib`, `html.parser`, `gzip`, `socket`). `requests` и `websockets` не
понадобились: зависимость от них появилась бы только вместе с полноценной
CDP-сессией.

MCP-клиент тоже написан на стандартной библиотеке (`subprocess`, `json`,
`threading`): официальный SDK `mcp` не используется. Упомянутый в README
`chrome-devtools-mcp` — сторонний npm-пакет Google; в поставку MLVH он не
входит и запускается только если пользователь сам добавил такой сервер.
